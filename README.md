# Garden Rust — Chunk with greedy meshing

Этот проект содержит пример на Rust, который создаёт 2D-чанк и выполняет простое жадное меширование (greedy meshing) для объединения соседних заполненных блоков в прямоугольники.

Особенности:
- Блоки рисуются зелёным цветом.
- Фон — голубой (sky blue).
- Результат сохраняется в output/chunk.png.

Запуск:

```bash
cargo run --release
```

После запуска откройте output/chunk.png — это изображение чанка.
